# Сервис управления списком гостей

## Назначение
Приложение помогает организатору мероприятия вести список гостей,
отслеживать статус приглашений и контролировать количество
свободных мест на событии.

## Целевая аудитория
Организаторы частных и корпоративных мероприятий: дни рождения,
свадьбы, конференции, встречи команд.

## Предметная область
Управление приглашениями на событие: учёт гостей, подтверждение
участия, контроль лимита мест.

## Основные сущности
- Событие — мероприятие с названием, датой и количеством мест.
- Гость — человек, которого приглашают на событие.
- Приглашение — связь гостя с событием.
- Статус — состояние приглашения (подтверждено / ожидает).

## Основные функции
- Проверка статуса приглашения по флагу подтверждения.
- Проверка возможности добавления гостя (наличие свободных мест).
- Формирование карточки гостя с примечаниями по возрасту и месту.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
